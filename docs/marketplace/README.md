# Marketplace submission artifacts (draft)

Files here are **templates** for a future PR to the [BB Community marketplace](https://github.com/get-bb/marketplace). They are not consumed by BB at install time.

| File | Purpose |
| --- | --- |
| `entry.draft.json` | Starting point for `entries/firstmate-control-plane.json` |
| `../PUBLISHING.md` | Maintainer checklist, tagging, and submit workflow |

At submission time, vendored icons and screenshots live in the **marketplace** repository, not in this plugin repo.
